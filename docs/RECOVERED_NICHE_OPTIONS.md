# Recovered Arc niche behaviors

Recovered from Arc product history and reconciled against the current product authority.

Core now / beta-critical:
- Unit Focus with explicit Lesson order and detach;
- Tack to next instructional day;
- Extend +1 instructional day with stable continuation identity;
- Copy to next instructional day;
- Fridge magnet bank for unscheduled Idea / Note / Lesson / Unit objects;
- full Unit tree movement and clipboard semantics;
- school-calendar-driven fixed date protection;
- class and content filters;
- fixed or last-used landing view;
- Quarter checkpoints;
- Year markers limited to Year Map;
- lightweight Magnet Details (notes/resources/fixed state) rather than formal lesson plan pages;
- same-day separate lanes / intentional stacking;
- truthful Save now + shortcut.

Useful next after core gate:
- compact mode;
- dark mode;
- prior-year reuse workflow beyond simple week reuse;
- selective Google Calendar overlays kept distinct from Arc plans.

Later / potentially paid by current canonical authority:
- Sub Plans (daily and emergency flows);
- Student Leaders nested under Sub Plans;
- template management/import;
- collaboration/shared spaces;
- optional teacher-controlled AI.

Do not restore simply because it existed historically:
- duplicate planning destinations for the same object model;
- fake source cards or invented school-calendar facts;
- permanent sticker trays outside Year Map;
- formal lesson-plan pages as the primary editor;
- demo data inside real workspaces;
- version-number CSS recovery layers.
