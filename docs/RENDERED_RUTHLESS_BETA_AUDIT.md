# Arc — Ruthless Rendered UI + Simulated Beta Audit

**Decision: NO-GO**

This is a **simulated 30-person panel**, not human research: 15 UI/product professionals and 15 teachers with varied schedules, experience, accessibility needs, planning habits, and device constraints. Scores are grounded in the current reconstruction branch, its passing Chromium workflows, and the actual success-state screenshots generated by CI.

## Current result

- Overall: **74.8/100**
- UI professionals: **77.4/100**
- Teachers: **72.2/100**
- Simulated unaided task success: **64.9%**
- Mean rating: **4.4/5**
- Five-star-equivalent ratings: **9/30**
- Release gate: **NO-GO**

## What is authentically better

- The full-screen shell is now browser-proven at 1440×900 and 1366×768.
- Fridge + expanded Must/Should/Could no longer grows the browser document.
- Unit creation and nested Lesson creation complete in Chromium.
- Unit Focus opens without changing Week.
- Month is a real editing surface: Unit-tree Copy/Paste works in Chromium.
- Must/Should/Could completes the red-circle → cross-out → delete lifecycle.
- The operation layer preserves Unit trees and Cut/Copy identity rules.
- Shift has fixed-date/no-school/collision preflight rather than blind movement.
- One planner stylesheet authority is enforced by test.
- The current visual system is recognizably Arc/Wax & Wing: League Spartan working UI, Georgia editorial hierarchy, cream/teal/gold/coral palette.

## Critical blockers

1. **Cloud/account persistence is still absent.** Local Save is truthful, but school↔home continuity is not beta-safe.
2. **Course-specific instructional calendars are incomplete.** A/B, rotating block, irregular meeting days and multi-campus schedules can still produce wrong planning behavior.
3. **Structural non-drag movement is incomplete.** Keyboard reachability passes, but keyboard-only users cannot yet perform every Unit/Lesson move/nest/detach workflow.
4. **Day is not yet the richer teach-from-it component already built on the branch.**
5. **Year is not yet wired to the corrected single-month mini-calendar component already built on the branch.**
6. **Semester remains too passive and too similar to Quarter.**
7. **Fridge composer is visually oversized in the rendered evidence because its internal grid allocation is wrong.**
8. **Calendar toolbar is too dense.** It remains legible but feels like a developer control strip at 1366px, especially with a folder open.
9. **Unit Focus remains form-heavy.** The fixed-date control and resources area need another art-direction pass.
10. **Exact approved Arc logo is being corrected in the asset route and must be re-render-verified before brand acceptance.**
11. **200% zoom, screen-reader workflows, touch, and reduced-motion rendered verification need dedicated gates.**
12. **School calendar upload / district-source automation is not implemented; onboarding is currently honest manual setup only.**

## Raised release bar remains

- UI professional mean ≥92/100; no individual <85.
- Teacher unaided success ≥95%.
- Core planning loop success 100% across all 30 personas.
- Mean product rating ≥4.6/5.
- ≥24/30 five-star-equivalent.
- 0 critical blockers, 0 dead primary controls, 0 silent clipping/data loss.
- 100% non-drag completion for critical planning tasks.
- 100% persistence/reload/account isolation.
- Exact rendered browser evidence on the exact candidate build.

The build is now worth continuing. It is **not beta-ready**.
