# Hostile Beta Protocol

No onboarding explanation is given before the first scenario.

## Teacher cohorts
- 5 new teachers
- 5 veteran teachers
- 5 special education/inclusion teachers
- 5 studio/art teachers
- 5 heavy smartboard/projector users
- 5 teachers who self-identify as reluctant technology users

## Consultant reviews
- front-end engineer
- accessibility specialist
- interaction designer
- ed-tech product designer
- privacy/security reviewer
- classroom technology specialist

## Scenarios
1. Your second-period class begins in four minutes. Run this lesson.
2. The projector disconnected for three minutes. Continue where you were.
3. A student asks for the restroom while cleanup is running.
4. You opened the wrong period. Recover without exposing another class roster.
5. You are on a 13-inch classroom laptop at 200% browser zoom.
6. You need the same lesson in another period, but a different roster.
7. The middle media stage is not needed today. Run directions full-width.
8. You can use only the keyboard.

## Collection
Record completion, time-to-recover, errors, hesitation points, accidental privacy exposure, abandonment, and confidence score. Do not count a task as passed merely because the tester eventually finds a workaround.
